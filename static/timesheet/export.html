Nested view in MongoDB Compass

The database also has a read-only view, employee_timesheets: one document per employee, with payrolls (21st to 20th), the three 10-day cycles inside each, and the entries inside those. It is created once by an admin with python -m backend.timesheet.nested_view create --yes. It is a view, so it never goes out of date and adds no load to the app. Edit entries only in timesheet_entries.
